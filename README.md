# 通讯录管理系统（C 语言）

基于《C程序设计》第五版第 6、7、9、10 章知识点实现的命令行通讯录，数据保存在本地文件中。

## 功能

- [x] 添加联系人
- [x] 显示全部联系人
- [x] 按姓名查找
- [x] 修改联系人
- [x] 删除联系人（数组前移）
- [x] 保存到文件 / 启动时读回

## 构建与运行

```bash
gcc main.c -o contacts
.\contacts
```

如果终端里中文显示为乱码，先执行：

```bash
chcp 65001
```

## 数据结构

```c
struct Contact {
    char name[21];
    char phone[21];
    char addr[41];
};
```

存储格式：`contacts.txt`，每行一条记录，字段以 `|` 分隔。
